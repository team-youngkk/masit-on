# PRD-DISCOVERY-003 지도 기반 탐색

## 1. 문서 정보

공개 맛집의 위치와 분포를 지도에서 탐색하는 1차 확장 제품 계약이다. WS-07과 양성훈이 최종 책임을 맡는다. 2026-08-03 UX 검토에서 지도 뷰포트를 서버 검색 조건에서 제거하고, 지도 이동 중에도 탐색 결과와 대체 목록을 유지하도록 변경했다.

## 2. 해결할 문제

목록의 주소만으로는 맛집 위치와 분포를 빠르게 파악하기 어렵다. 반대로 현재 화면 영역만 서버 조건으로 사용하면 사용자가 지도를 조금 이동했을 때 방금 검색한 맛집과 목록이 사라져 탐색 맥락이 끊긴다.

사용자는 이름·자치구·음식 카테고리·유튜버 조건으로 찾은 맛집 집합을 유지한 채 지도를 자유롭게 이동하고, 화면 밖 마커도 대체 목록에서 계속 확인할 수 있어야 한다.

## 3. 목표

- 유효 좌표가 있는 공개 맛집을 마커와 접근 가능한 대체 목록에 같은 집합으로 표시한다.
- URL 탐색 조건이 바뀔 때만 서버 결과를 갱신한다.
- 지도 이동·확대·축소가 기존 결과와 선택 상태를 제거하지 않게 한다.
- 사용자 현재 위치와 지도 뷰포트를 서버에 전송·저장·로그하지 않는다.

## 4. 사용자 여정

### 4.1 최초 진입과 필터 탐색

1. 사용자가 지도 화면을 연다.
2. 시스템은 URL의 `query`, `district`, `category`, `creatorId` 조건으로 좌표가 있는 공개 맛집을 조회한다.
3. 결과를 지도 마커와 대체 목록에 동일하게 표시한다.
4. 사용자가 탐색 조건을 제출·초기화하거나 뒤로·앞으로 이동해 URL 조건이 바뀌면 새 조건으로 재조회한다.

### 4.2 지도 이동

1. 사용자가 지도를 이동·확대·축소한다.
2. 지도 화면 중심과 뷰포트만 클라이언트에서 변경된다.
3. 서버 요청을 새로 보내지 않고 기존 마커·대체 목록·선택 상태를 유지한다.
4. 화면 밖 마커는 지도에 보이지 않을 수 있지만 대체 목록에서 제거하지 않는다.

### 4.3 선택과 상세 이동

1. 사용자가 마커 또는 목록 항목을 선택한다.
2. 마커와 목록의 같은 맛집을 선택 상태로 만들고 이름·카테고리·주소 요약을 표시한다.
3. 목록에서 화면 밖 맛집을 선택하면 지도는 해당 마커로 이동할 수 있다.
4. 사용자는 요약에서 맛집 상세로 이동한다.

## 5. 포함 범위

- Kakao Maps JavaScript API 기반 지도 렌더링·이동·확대·축소
- 이름·자치구·음식 카테고리·유튜버 조건 기반 마커 API
- 최대 200개의 마커와 같은 결과를 사용하는 대체 목록
- 마커·목록 선택 동기화와 상세 이동
- 좌표 없는·비공개·삭제 맛집 제외
- SDK 오류·API 오류·호출 제한의 독립 안내

## 6. 제외 범위

- 현재 지도 뷰포트의 `south`·`west`·`north`·`east` 서버 전송과 공간 AND 조건
- 지도 이동 완료 이벤트를 이용한 서버 재조회·debounce
- 현재 위치, 거리·반경, 길찾기·경로 추천
- 마커 클러스터링, 무한 지도 탐색, PostGIS
- 사용자별 지도 위치·이동 이력 저장

## 8. 화면 상태

| 상태 | 표시 | 다음 행동 |
|---|---|---|
| 결과 있음 | 전체 마커, 같은 대체 목록 | 선택, 지도 이동, 필터 변경 |
| 결과 없음 | 조건에 맞는 맛집 없음 | 조건 초기화·변경 |
| 200개 초과 | 조건이 너무 넓다는 안내 | 이름·자치구·카테고리·유튜버 조건 추가 |
| 지도 이동 | 기존 결과와 선택 유지 | 계속 이동하거나 목록 선택 |
| SDK 실패 | 지도 오류와 재시도, 대체 목록 유지 | 재시도·목록·상세 이용 |
| API 실패·429 | 마지막 정상 결과 유지와 오류 안내 | 대기·필터 재시도 |

## 9. 성공 기준과 완료 조건

- 지도 이동 전후 API 호출 수가 증가하지 않고 마커·목록 결과가 유지된다.
- URL 탐색 조건 변경 시에만 새 API 조회가 발생한다.
- 화면 밖 맛집도 대체 목록에 남고 목록 선택으로 해당 마커에 접근할 수 있다.
- 결과 200/201개, 공개·삭제·좌표 없음, 필터 AND와 중복 제거 경계가 검증된다.
- 요청·응답·로그에 지도 뷰포트와 사용자 현재 위치가 없다.
- 코드의 bounds 계약 제거는 [E1-T11](../../../08-planning/expansion-1-task-breakdown.md)에서 구현했다.
