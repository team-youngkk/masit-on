# 1차 확장 저해상도 와이어프레임

## 1. 목적과 사용법

이 문서는 정보 구조, 핵심 제어, 상태와 화면 간 이동을 확정하는 저해상도 와이어프레임이다. 색상·타이포그래피·간격의 최종 시각 설계는 기존 참조 이미지와 프론트엔드 디자인 규칙에서 정한다. 아래 텍스트에 없는 데이터나 기능을 구현 범위로 해석하지 않는다.

## 2. 공통 Layout

```text
┌──────────────────────────────────────────────────────────────┐
│ 맛잇온  [맛집 탐색] [지도]         [관리자*] [로그인 또는 내 메뉴] │
├──────────────────────────────────────────────────────────────┤
│ 현재 화면 제목 / 필요한 경우 검색·필터·상태 메시지              │
│                                                              │
│                      화면별 본문                              │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 서비스 정보 · 외부 링크 · 정책                                │
└──────────────────────────────────────────────────────────────┘
```

- 비로그인 헤더에는 `로그인`만 표시한다.
- 로그인 헤더의 `내 메뉴`에서 `내 찜`, `최근 본 맛집`, `로그아웃`, `회원 탈퇴`에 접근한다.
- `관리자` 링크는 현재 세션 역할이 정확히 `ADMIN`일 때만 표시하고 정확한 `/admin`으로 이동한다. `MEMBER`, 비로그인과 세션 복구 중에는 표시하지 않는다.
- 인증·개인화 기능 장애 중에도 `맛집 탐색`, `지도`, `유튜버 상세` 진입을 막지 않는다.
- 모바일에서는 헤더 탐색을 축약하되 동일 기능에 키보드와 보조 기술로 접근할 수 있어야 한다.

## 3. 회원가입·로그인

### WF-AUTH-001 로그인

```text
┌───────────────────────────────┐
│ 로그인                         │
│ 이메일    [________________]   │
│ 비밀번호  [________________]   │
│ [ 로그인 ]                     │
│                               │
│ 회원가입                       │
│ 비밀번호를 재설정할 수 있어요   │
│                               │
│ 오류/제한 메시지 영역           │
└───────────────────────────────┘
```

회원과 관리자가 함께 쓰는 `/login` 화면이며 역할 선택은 두지 않는다. `/admin/login`은 이 폼을 중복 표시하지 않고 `/login?returnTo=/admin`으로 이동한다. 로그인 `401`은 계정 상태를 드러내지 않는 인증 실패로, `5xx`·네트워크 오류는 입력을 그대로 보존하는 일시 장애와 `다시 시도` 행동으로 구분한다.

### WF-AUTH-002 회원가입·이메일 인증

```text
┌───────────────────────────────┐
│ 회원가입                       │
│ 이메일    [________________]   │
│ 비밀번호  [________________]   │
│ 비밀번호 확인 [_____________]  │
│ 비밀번호 정책 설명              │
│ [ 가입 요청 ]                   │
├───────────────────────────────┤
│ 이메일을 확인해 주세요          │
│ 계정 존재 여부와 무관한 안내     │
│ 인증 코드 [ _ _ _ _ _ _ _ _ ] │
│ [ 8자 코드로 인증 ]              │
│ [ 인증 메일 다시 요청 ]          │
│ 재요청 가능 시각/제한 안내       │
└───────────────────────────────┘
```

### WF-AUTH-003 인증 만료·권한 오류

```text
┌───────────────────────────────┐
│ 세션이 만료되었습니다            │
│ 변경 내용은 저장되지 않았습니다. │
│ [ 다시 로그인 ] [ 공개 화면 ]    │
└───────────────────────────────┘

┌───────────────────────────────┐
│ 접근할 수 없습니다               │
│ 현재 계정에는 이 기능의 권한이    │
│ 없습니다.                       │
│ [ 이전 화면 ] [ 맛집 탐색 ]      │
└───────────────────────────────┘
```

재발급이 성공하면 만료 화면을 표시하지 않고 원래 요청을 한 번만 재시도한다. 권한 오류에는 로그인을 반복하도록 유도하지 않는다.

### WF-AUTH-004 비밀번호 재설정

```text
┌───────────────────────────────┐
│ 비밀번호 재설정                │
│ 이메일    [________________]   │
│ [ 재설정 메일 요청 ]           │
│ 계정 상태·메일 발송 여부와      │
│ 무관한 동일 접수 안내           │
├───────────────────────────────┤
│ 새 비밀번호 [_______________]  │
│ 비밀번호 확인 [_____________]  │
│ [ 비밀번호 변경 ]              │
│ Token 만료·변조·재사용 시       │
│ [ 새 메일 요청 ]               │
└───────────────────────────────┘
```

재설정 완료 뒤 기존 세션이 모두 폐기됐음을 알리고 로그인 화면으로 이동한다. 오류 화면은 이메일 존재 여부를 설명하지 않는다.

### WF-AUTH-005 로그아웃 실패

```text
┌───────────────────────────────┐
│ 로그아웃을 완료하지 못했습니다.  │
│ 이 기기의 인증정보는 제거했지만   │
│ 서버 세션 폐기를 확인하지 못했어요.│
│ [ 복구 후 다시 시도 ] [공개 화면] │
└───────────────────────────────┘
```

Redis 장애 중에는 로그아웃 완료 문구를 표시하지 않는다. 복구 후 서버 Refresh 세션 폐기가 확인돼야 성공 상태로 전환한다.

### WF-AUTH-006 회원 탈퇴 확인·진행

```text
┌───────────────────────────────┐
│ 회원 탈퇴                      │
│ 계정정보·찜·최근 기록과 모든     │
│ 인증 상태가 삭제됩니다.          │
│ [ 취소 ] [ 탈퇴 확인 ]           │
├───────────────────────────────┤
│ 탈퇴 처리 중                    │
│ 로그인과 같은 이메일 재가입은     │
│ 정리 완료까지 차단됩니다.         │
└───────────────────────────────┘

┌───────────────────────────────┐
│ 탈퇴 정리가 지연되고 있습니다.    │
│ 로그인 차단은 유지됩니다.         │
│ 자동 재시도 중이며 운영 복구       │
│ 대상입니다.                      │
│ [ 공개 화면 ]                    │
└───────────────────────────────┘
```

지연 화면은 탈퇴가 취소되었거나 완료된 것처럼 표현하지 않는다. 15분 재시도·1시간 운영 알림·24시간 내 완료 또는 수동 복구는 운영 정책으로 유지한다.

### WF-AUTH-007 관리자 진입과 내비게이션

```text
┌──────────────────────────────────────────────────────────────┐
│ 맛잇온 [맛집 탐색] [지도]                    [관리자] [내 메뉴] │
├──────────────────────────────────────────────────────────────┤
│ 관리자 대시보드                                              │
│ [맛집 등록] [유튜버 등록] [영상 등록] [방문 관계 등록]          │
│                                                              │
│ 선택한 관리자 화면                                            │
└──────────────────────────────────────────────────────────────┘
```

- 공통 헤더의 `관리자`는 `ADMIN` 세션에서만 보이고 목적지는 정확히 `/admin` 대시보드다.
- 관리자 내비게이션은 현재 pathname과 정확히 일치하는 항목 하나에만 `aria-current="page"`를 제공한다.
- 비로그인이 `/admin/**`에 직접 접근하면 검증된 같은 Origin allowlist 경로만 `returnTo`로 보존해 `/login`으로 이동한다.
- `MEMBER`의 직접 접근은 별도 Route나 로그인 화면으로 보내지 않고 관리자 Layout 안에 `403` 권한 없음 StatePanel을 표시한다.
- 세션 복구 중에는 관리자 본문이나 역할 전용 링크를 먼저 표시하지 않는다. `403`은 재발급하지 않고, `5xx`·네트워크 오류는 현재 화면과 입력을 보존해 다시 시도할 수 있게 한다.

## 4. 내 찜 목록

```text
┌────────────────────────────────────────────────────┐
│ 내 찜                                      최신순  │
│ ┌────────────────────────────────────────────────┐ │
│ │ 맛집 이름 · 자치구 · 대표 카테고리       [찜 해제]│ │
│ └────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────┐ │
│ │ 맛집 이름 · 자치구 · 대표 카테고리       [찜 해제]│ │
│ └────────────────────────────────────────────────┘ │
│                     [이전] 1 / N [다음]             │
└────────────────────────────────────────────────────┘
```

빈 상태:

```text
┌───────────────────────────────┐
│ 아직 찜한 맛집이 없습니다.      │
│ 다시 찾고 싶은 맛집을 저장해     │
│ 보세요.                         │
│ [ 맛집 탐색 ]                   │
└───────────────────────────────┘
```

비공개 자원은 숨기고 삭제 자원은 관계를 제거한다. 찜 해제가 실패하면 카드를 유지하고 해당 제어 주변에 오류와 재시도를 표시한다.

## 5. 최근 본 맛집

```text
┌────────────────────────────────────────────────────┐
│ 최근 본 맛집                         최근 30일·최대 50개 │
│ ┌────────────────────────────────────────────────┐ │
│ │ 맛집 이름 · 자치구 · 대표 카테고리  마지막 조회 시각 │ │
│ └────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────┐ │
│ │ 맛집 이름 · 자치구 · 대표 카테고리  마지막 조회 시각 │ │
│ └────────────────────────────────────────────────┘ │
│                     [이전] 1 / N [다음]             │
└────────────────────────────────────────────────────┘
```

빈 상태는 `최근 확인한 맛집이 없습니다`와 `맛집 탐색` 행동을 제공한다. 비공개·삭제·30일 만료 자원은 표시하지 않는다. 기록 저장이 실패해도 공개 맛집 상세는 그대로 표시하며, 개인 메뉴에만 `최근 기록을 저장하지 못했습니다`와 재시도 상태를 제공한다.

## 6. 지도 탐색

### 데스크톱

```text
┌──────────────────────────────────────────────────────────────┐
│ [이름] [자치구] [음식] [유튜버] [조건 초기화]                  │
├──────────────────────────────────┬───────────────────────────┤
│ Kakao 지도                        │ 검색 결과 맛집 목록         │
│                                  │ ┌───────────────────────┐ │
│       ● A             ● B         │ │ A · 카테고리 · 주소    │ │
│                                  │ └───────────────────────┘ │
│             ● C                  │ ┌───────────────────────┐ │
│                                  │ │ B · 카테고리 · 주소    │ │
│ [−] [+]                           │ └───────────────────────┘ │
├──────────────────────────────────┴───────────────────────────┤
│ 선택: A · 대표 카테고리 · 주소 요약                [상세 보기] │
└──────────────────────────────────────────────────────────────┘
```

### 모바일

```text
┌───────────────────────────────┐
│ 검색·필터 [열기]               │
│ Kakao 지도                     │
│      ● A        ● B            │
│ [−] [+]                        │
├───────────────────────────────┤
│ 선택 맛집 요약      [상세 보기] │
├───────────────────────────────┤
│ 검색 결과 맛집 목록             │
│ A · 카테고리 · 주소             │
│ B · 카테고리 · 주소             │
└───────────────────────────────┘
```

- 마커와 목록은 같은 선택 상태를 사용한다.
- 목록은 지도 조작이 어려운 사용자를 위한 동등한 탐색 경로다.
- 지도 이동·확대·축소는 서버 재조회 없이 기존 마커·목록·선택을 유지한다.
- 200개 초과 시 결과 일부를 표시하지 않고 `검색 조건을 추가해 주세요` 상태를 표시한다.
- 빈 결과는 `검색 조건과 일치하는 맛집이 없습니다`와 조건 초기화를 제공한다.
- SDK 오류 시 지도 영역 대신 오류·재시도를 표시하되 대체 목록과 다른 공개 화면은 유지한다.
- 현재 위치 버튼이나 위치 권한 요청은 두지 않는다.

## 7. 유튜버 상세

```text
┌──────────────────────────────────────────────────────────────┐
│ [프로필 이미지] 현재 채널명                                  │
│ @handle · 채널 소개                              [YouTube 채널]│
├──────────────────────────────────────────────────────────────┤
│ 방문 맛집                                                     │
│ [맛집 카드] [맛집 카드] [맛집 카드]               [이전/다음] │
│ 또는: 공개된 방문 맛집이 없습니다.                             │
├──────────────────────────────────────────────────────────────┤
│ 근거 영상                                                     │
│ [썸네일·영상 제목] [썸네일·영상 제목]             [이전/다음] │
│ 또는: 공개된 근거 영상이 없습니다.                             │
└──────────────────────────────────────────────────────────────┘
```

- 방문 맛집과 근거 영상의 페이지 상태는 서로 독립적이다.
- 프로필 이미지나 소개가 선택 정보로 확정되면 값이 없을 때 영역을 생략하고 대체 데이터를 추정하지 않는다.
- Creator가 비공개·삭제·외부 이용 불가이면 찾을 수 없음 화면을 제공한다.
- 구독자 수·조회 수·인기 순위·팔로우 제어를 표시하지 않는다.

## 8. 찾을 수 없음·삭제·비공개 상태

```text
┌───────────────────────────────┐
│ 요청한 정보를 찾을 수 없습니다. │
│ 삭제되었거나 공개되지 않은       │
│ 정보일 수 있습니다.              │
│ [ 이전 화면 ] [ 맛집 탐색 ]      │
└───────────────────────────────┘
```

외부 응답은 자원의 삭제·비공개·이용 불가 원인을 구분해 노출하지 않는다. 개인 목록에서는 해당 항목을 카드 대신 오류 자리표시자로 남기지 않는다.

## 9. 화면 상태 검수표

| 화면 | 정상 | 빈 상태 | 오류·경계 |
|---|---|---|---|
| 로그인·회원가입 | 입력·접수·인증 완료 | 해당 없음 | 동일 인증 오류, 제한, 메일 장애 |
| 내 찜 | 최신순 카드·페이지 | 찜 없음 | 만료, 해제 실패, 비공개·삭제 숨김 |
| 최근 본 | 최신 조회순 카드·페이지 | 기록 없음 | 만료, 비공개·삭제 숨김 |
| 지도 | 마커·목록·선택 동기화, 이동 시 결과 유지 | 빈 검색 결과 | 200개 초과, SDK 오류, 호출 제한 |
| 유튜버 상세 | 채널·맛집·영상 | 두 독립 빈 목록 | 찾을 수 없음, 연결 자원 제외 |
| 공통 인증 | 재발급 후 흐름 유지 | 해당 없음 | 만료, Redis 장애, 권한 오류 |
| 관리자 진입 | `ADMIN` 헤더 링크·기능별 정확한 활성 메뉴 | 해당 없음 | 비로그인 안전한 복귀, `MEMBER` 403, 복구 장애 |

## 10. 반응형·접근성 검수

- 360px, 390px, 768px, 1280px와 1440px 폭에서 핵심 행동을 가리지 않는다.
- 모든 입력에는 보이는 레이블, 오류 연결과 키보드 초점 순서를 제공한다.
