# 큐레이션 API

[큐레이션 API](curation-api.md)는 공개 조회와 관리자 편집 경로를 함께 정의한다. Curation은 게시 생명주기와 수동 표시 순서를 소유하며 개인 Collection 모델을 재사용하지 않는다.
