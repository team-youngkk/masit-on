# 날짜·시간 계약

## 1. 표준 표현

- 날짜만 의미하는 값은 ISO 8601 `YYYY-MM-DD` 문자열을 사용한다.
- 특정 시점을 의미하는 날짜·시간은 RFC 3339 형식과 명시적 UTC 오프셋을 사용한다. UTC 예시는 `2026-07-24T03:00:00Z`다.
- 오프셋 없는 로컬 날짜·시간 문자열은 응답하지 않는다.
- 서버 내부 저장 방식과 기준 시간대는 후속 데이터 모델 또는 ADR에서 결정한다.

## 2. MVP 적용

1차 MVP는 실제 방문일을 관리하지 않고 영상 게시일을 방문일로 대체하지 않는다. 영상 게시일은 사용자 조회 범위에서 제외돼 현재 공개 응답에 포함하지 않는다. 관리자 영상 등록도 원본 URL만 입력하며 외부 조회 결과의 게시일을 계약 필드로 노출하지 않는다.

향후 확정된 날짜 필드가 추가되면 게시일과 방문일을 서로 다른 필드와 의미로 정의하고 이 공통 형식을 적용한다. 값의 의미상 날짜만 필요한데 임의 시각이나 서버 시간대를 덧붙이지 않는다.
