## 3. 문제 현상

- 재현 조건: PR #126 본문과 선행 상태 검토 문서의 최종 판정을 함께 확인한다.
- 실제 결과: 문서는 운영 검증이 남아 게이트를 차단하지만 PR 본문은 `Closes #105`로 Task 완료를 선언했다.
- 기대 결과: 중간 기준선 PR은 이슈를 연결하되 완료를 선언하지 않아야 한다.
- 영향 범위: E2-T01 완료 상태와 E2-T02 이후 구현 착수 판단이 실제 검증 상태보다 앞설 수 있다.

## 4. 근본 원인

PR 생성 시 저장소의 일반적인 이슈 연결 형식을 기계적으로 적용하면서, 이 PR이 E2-T01 완료 PR이 아니라 미충족 조건을 보존하는 중간 기준선 PR이라는 판정을 본문 첫 줄에 반영하지 못했다. 코드·테스트 결과와 Task 완료 상태를 별개의 증거로 다뤄야 하지만 PR 메타데이터에서 이를 구분하지 않은 것이 원인이다.

## 5. 해결

- 변경 내용: PR 본문 첫 줄을 `Closes #105`에서 `Refs #105`로 변경했다.
- 선택 이유: 운영 검증을 수행한 것처럼 기록하지 않으면서 관련 이슈와의 추적성은 유지한다.
- 변경 파일: `docs/troubleshooting/README.md`, `docs/troubleshooting/pr-126-e2-t01-completion-reference-review.md`
- 고려한 대안: 운영 검증 완료 후 이슈를 닫는 방법은 현재 증거가 없어 적용하지 않았다.
